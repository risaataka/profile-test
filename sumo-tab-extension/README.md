# ちゃんこタブ力士 (Chanko Tab Rikishi)

タブを開けば開くほど、画面のすみの**やせた男性が力士に育っていく**Chrome拡張機能です。
24階級あり、**横綱**になると画面に向かって塩をまきはじめ、その塩が画面の下にだんだん積もります。

> ねらい: 見ていて楽しい ／ でも育ちすぎると邪魔になってきて、**タブを閉じたくなる**。

## 画面のイメージ

- あぐらをかいた男性が、ずっとちゃんこ鍋を食べて口をもぐもぐしている
- タブが増えると **白く点滅 → それから大きくなる**（昇進）
- タブを閉じると、しょんぼりして小さくなる（降格）
- 横綱（60タブ〜）になると 3秒ごとに塩をまき、塩は画面下に積もって視界をふさいでいく
- 横綱から落ちると、積もった塩は片付けられる

## 階級とまわしの色（冠位十二階）

まわしの色は**冠位十二階**（徳・仁・礼・信・義・智／各 大・小）に対応。
冠位ひとつにつき2階級（薄い→濃い）、色ひとつにつき4階級で、合計 6色 × 4 = **24階級**。
下から 智（黒）→ 義（白）→ 信（黄）→ 礼（赤）→ 仁（青）→ 徳（紫）と上がっていきます。

| 階級 | 番付 | 冠位 | まわしの色 | 必要タブ数 |
|---|---|---|---|---|
| 1–4 | 序ノ口 〜 幕下十五枚目 | 小智・大智 | 黒（だんだん漆黒に） | 1・2・3・4 |
| 5–8 | 幕下十枚目 〜 十両十三枚目 | 小義・大義 | 白（だんだん純白に） | 5・6・7・8 |
| 9–12 | 十両九枚目 〜 十両筆頭 | 小信・大信 | 黄 | 9・10・12・14 |
| 13–16 | 前頭十六枚目 〜 前頭七枚目 | 小礼・大礼 | 赤 | 16・18・20・23 |
| 17–20 | 前頭五枚目 〜 前頭筆頭 | 小仁・大仁 | 青 | 26・30・34・38 |
| 21–24 | 小結・関脇・大関・**横綱** | 小徳・大徳 | 紫 | 43・48・54・**60** |

正確な対応は [`src/ranks.js`](src/ranks.js) を参照（ツールバーのアイコンをクリックすると全24階級が一覧で出ます）。

## インストール（開発者モード）

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」→ この `sumo-tab-extension` フォルダを選択
4. 適当なページを開き直すと、左上に力士が座ります

## ツールバーのポップアップ

- いまの番付・冠位・まわしの色・タブ数
- 「あと◯枚開くと昇進 ／ ◯枚閉じれば降格」
- 24階級の一覧（現在位置がハイライト）
- 表示のオン/オフ、塩まきのオン/オフ、すわる位置（四隅）

## 軽さのための設計

タブをためこむ人ほどブラウザは重いので、拡張自体は極力なにもしないようにしています。

- タブ数の集計は **200ms のデバウンス**つき。変化がなければ書き込みもしない
- サービスワーカー → 各タブの通信は **`chrome.storage.onChanged` だけ**（タブ数ぶんの `sendMessage` をしない）
- 常時動くアニメーション（もぐもぐ・湯気・まばたき）は **CSS のみ**。JS のループは塩が着地した瞬間だけ
- **裏に回ったタブは `animation-play-state: paused` で完全停止**し、塩まきタイマーも止める
- 塩の粒は CSS アニメーションで飛び、着地時に山の高さの配列（48列）へ足すだけ。同時に飛ぶ粒は最大120個
- `prefers-reduced-motion` を尊重
- shadow DOM ＋ `pointer-events: none` なので、ページの CSS も操作も一切邪魔しない
- iframe には出さない（`all_frames: false`）

## ファイル構成

```
manifest.json        MV3 マニフェスト
src/ranks.js         24階級の定義（番付・冠位・色・必要タブ数）
src/rikishi.js       力士のSVGを組み立てる（太さは階級から算出）
src/styles.js        shadow DOM に流し込む CSS（content / popup で共有）
src/background.js    タブ数を数えて storage に書くサービスワーカー
src/content.js       ページ上の表示・昇進演出・塩まき・積もる塩
src/popup.html/js    ツールバーのポップアップ
icons/               アイコン（dev/make-icons.mjs で生成）
dev/                 開発用。拡張の動作には不要
```

## 開発用ツール（`dev/`）

拡張機能の実行には使いません。ブラウザで直接開いて確認するためのものです。

- `dev/preview.html` — 24階級の見た目を一覧（`?stages=1,12,24` で絞り込み）
- `dev/sandbox.html` — `chrome.*` を偽装して content script をそのまま動かす。スライダーでタブ数を変え、昇進・降格・塩まきを確認できる
- `dev/icon.html` + `dev/make-icons.mjs` — `icons/*.png` の生成（playwright が必要）
